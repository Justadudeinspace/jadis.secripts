# Changelog

## 0.1.0 — 2026-10-28

Initial Python arsenal: 20 registered diagnostic operations, five preparation recipes, sanitized
receipts, secret-aware archaeology, host diagnostics and an accessible 1337 console. Recovery Lab
introduces the TWRP backend, static tree audit, boot-header inspection, explicit source/build planning,
artifact collection and manual qualification reports. Source/build integration is experimental;
actual compilation and hardware qualification are not established by this release.
