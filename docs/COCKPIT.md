# Operator cockpit

`js 1337` is a view/controller over JS contracts. Its opening snapshot is bounded and
passive. Tool presence is distinct from readiness; devices are not interrogated on
opening. V explicitly refreshes with transport enumeration.

Use IMG, RAM, RY, DOC, DOS, RCP, HIST and AI shortcuts. Namespace help appears before
an argument prompt; normal parsing, risk and receipts still apply. E lists advanced
developer categories. Existing category keys remain supported. T reads receipts,
A shows sanitized archaeology, S searches, H explains, Q leaves.

Small Termux screens receive plain flowing text rather than fragile cursor positioning.
NO_COLOR disables escape styling. Non-TTY mode gives a described preview and exits;
`js 1337 --json` returns the complete structured dashboard without device enumeration.
The beginner alternative is `js guide`. No cockpit shortcut grants extra authority.
