Read the [Phase 5 gap gate](research/phase5-gap-matrix.md),
[source ledger](research/phase5-sources.json), [baseline audit](research/phase5-baseline.json)
and [historical archaeology](research.md). Internet material is untrusted input.

Primary Android docs/source constrain formats/architecture. Pinned device-tree files
are static research samples with author/organization context; upstream declarations
are not local known-working proof. Community failures supply hypotheses, not rules
that can auto-repair a checkout. Unavailable sources and license uncertainty remain
recorded. No giant trees, firmware, signing keys or downloaded executables are bundled.

The Phase 5 dataset links firmware/image observations, tree decisions and source/build
requirements where evidence exists; a complete stock-firmware-to-successful-recovery
chain remains missing. Prior synthetic/oracle/corpus evidence is not relabeled as
modern real-device evidence. See [credits](../CREDITS.md).

configuration declarations to pinned file/line/hash evidence. The build-failure
